# AI Usage Log

This project used AI assistance during development.

## Feature 1: Express CRUD API
- **Prompt/context provided:** Build a small Express REST API for daily tasks with CRUD routes, proper status codes, and organized files.
- **AI suggestion:** Structure the API into separate route, middleware, and data files and use a JSON-backed data store.
- **Outcome:** Accepted and adapted. I kept the structure, but rewrote the implementation to fit the task manager use case.
- **Validation:** Verified route behavior manually and ensured the API returns JSON responses and REST-style codes.
- **Limitations encountered:** Some generated examples were too dashboard-focused, so I redirected the data model toward daily tasks.

## Feature 2: React Task Manager UI
- **Prompt/context provided:** Build a polished UI for managing daily tasks like groceries, dinner, and errands.
- **AI suggestion:** A card-based layout with task creation, filtering, completion toggles, and deletion.
- **Outcome:** Accepted with modifications. I simplified the layout for daily use and adjusted labels to sound like a personal task manager.
- **Validation:** Built the client, reviewed the rendered UI, and confirmed the data flow matched the API.
- **Limitations encountered:** Some suggestions leaned too much toward assignment tracking, so I changed them to everyday task management.
